# Vyakti Studio design direction

Owner-approved direction, 2026-09-14: futuristic, clean, premium metallic silver.
The Studio is an operating interface: recording, teaching and testing must be
obvious. Silver surfaces, ink typography, precise spacing and restrained depth
replace the forest-green oversized recording dial. Red is reserved for active
recording and destructive actions. Status never depends on color alone.

Keep a stable content column and predictable type scale across idle, recording,
preview, upload, error and retry. The main action stays visible on small phones.
Decoration must never become the largest interaction or overlap text. A compact
audio instrument may show real recording levels; it is not a background for copy.
Keep imagery purposeful and separate from controls.

Use concise labels and one short contextual sentence where needed. Step labels
stay comparable in size; explanatory text spans the flow rather than squeezing
into one step. Translate lifecycle states into ordinary language. Errors explain
what happened and the next action without blaming the user for platform failures.

Motion connects states and acknowledges input: restrained easing, stable layout,
clear drawer entry/exit, and real recording feedback. Never animate text size or
create perpetual layout movement. Honor reduced motion. Nonessential notices
expire, pause while read and dismiss immediately; errors remain actionable.

Verify 360/390px phones, intermediate widths and desktop using the actual
recording, preview, failed-upload, menu and input states. Keep 44px touch targets,
visible keyboard focus, readable contrast and safe-area spacing. Existing owner
screenshots are failure evidence, not stale captures to explain away.
