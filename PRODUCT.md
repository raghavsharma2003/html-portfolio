# Vyakti

Vyakti helps an expert turn their own knowledge, voice and communication style
into an AI that answers their audience. Teaching is the first vertical, not the
boundary. The creator teaches and corrects their AI; each visitor has a separate
conversation and memory. These are experiences in one product.

The main journey is sign in, Feed it, Meet it, Deploy it. Any supported account
must be able to create its own workspace. An account-specific retained-reference
voice experiment is a diagnostic, not a substitute for this journey.

The immediate release is private testing. Successful recording, uploads,
grounded answers, useful memory and voice likeness are the core outcomes.
Public verification and rollout are deferred. Existing data isolation and honest
permission states remain. Azure/Foundry serves models using the startup-grant
subscription. Meera remains a separate product.

The owner explicitly rejected the current mobile recorder and navigation on
2026-09-14: overlapping labels, oversized decoration, unstable layout, technical
status strings, persistent notifications and unexplained upload failures. Fix
these actual states before calling the journey ready. A passing fixture or CI
gate does not establish a successful live user journey or competitive quality.

Current measured implementation and remaining proof live in context/STATE.md
and docs/handoff/2026-09-14/PRODUCT-STATUS.md. Do not infer delivery from this brief.
