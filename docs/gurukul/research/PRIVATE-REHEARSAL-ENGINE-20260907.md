# Private text rehearsal compiler and orchestration

This candidate lets an expert test one question against an explicitly selected private draft and one owner-authored context item. It does not publish a personality or create identity, voice or relationship-memory authority.

The store owns actual account attestation, canonical source evidence, snapshot checks, encryption and exclusive dispatch. The compiler accepts a distinct private authority shape; it does not invent the IDs required by the existing published compiler. Only shared prompt primitives are exported, with existing published outputs checked byte-for-byte on two inputs.

The HTTP service uses the existing Azure structured-output adapter, token budget and shared reply gates. Admission precedes adapter checks so retries can read saved results during a provider outage. A reservation and exclusive store claim precede provider begin. There is no automatic paid retry. A known pre-begin abort may release an exclusively held reservation; an ambiguous dispatch cannot. Actual usage is settled before output validation and delivery authorization. A blocked answer can still carry a real cost.

Questions are limited to 2,000 UTF-16 units and selected evidence to 8,000, with bounded draft fields and total prompt length. This initial vertical supports maths, physics and chemistry. The language rule supports Hindi, Hinglish and English, but prompt structure alone does not establish answer quality in any language.
