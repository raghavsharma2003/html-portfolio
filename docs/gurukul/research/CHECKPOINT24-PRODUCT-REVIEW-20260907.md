# Vyakti: checkpoint24 product review

September 7, 2026. Development candidate, not a public release.

Vyakti's first product is an expert's private AI: add knowledge, test an answer, correct the way it responds, then explicitly review what becomes available to others. Voice, memory and personality belong to that same experience. They are not accepted merely because their components exist.

The next direct usability change is **Test this source** from Feed, with authoritative readiness checks and preservation of the unsent question during a same-account, same-clone round trip. It must never automatically save, ask a model or grant permission.

The visual direction remains a calm light interface with strong primary actions, readable type, mobile layouts and restrained state-based motion. The inspected advanced teacher editor is still long and text-heavy. There is no evidence supporting a claim that this product currently beats ElevenLabs, Delphi or Fish Audio.

The latest completed full runner is checkpoint23: 23 of 24 software checks passed, with two outdated test assumptions failing. Those fixtures are repaired in checkpoint24. The actual relational database checks are tracked separately from runners that explicitly skipped them. Final checkpoint24 acceptance is pending.
