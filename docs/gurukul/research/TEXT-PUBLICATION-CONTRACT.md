# Early text publication API contract

Checkpoint-next working contract, 2026-09-08. Implementation only; no deployment or live authority. Existing clone identity, voice, training and Room gates are unchanged.

Owner endpoint `/api/replica-text-publication`, authenticated GET/POST. Visitor endpoint `/api/text-publication`, GET open is discovery, all other operations authenticate the visitor. All responses no-store. Public destination `/studio?publication=<public_id>`; server returns `public_id`, not a hardcoded origin.

Owner GET `op=readiness&replica_id=...&sheet_id=...&context_item_id=...` returns `{readiness}`: `{replica_id,state,blockers:[{code,responsibility:'owner'|'platform'}],drafts,context_items,selected,statement_set,statements,can_publish,publications}`. `selected` is null or `{review_hash,source_name,projection,material_text,terms}`. The owner reviews the entire selected material and allowlisted teaching projection; all statements start unchecked. Readiness and status never call a model. `publications` contains owner-safe publication summaries.

Owner POST `op=publish` sends `{replica_id,sheet_id,context_item_id,publication_id:<new client UUID>,expected_review_hash,statement_set,attestations:{every returned statement id:true}}`; returns `{publication}` with HTTP201 on creation or200 replay. Publication ID is also public ID. Changed-payload replay rejects. Private draft changes do not change published content. An explicit new publication requires unpublishing the old link first; revoked IDs never re-activate. No implicit replace operation in v1. Future verified voice can attach to the same still-active public ID after its separate real grant.

Owner GET `op=status&replica_id=...&publication_id=...` returns `{publication}`. POST `op=unpublish` same IDs returns `{publication}` revoked with payload erasure. Publication summary `{public_id,replica_id?,state:'active'|'revoked'|'expired'|'unavailable',version:1,title,subject_domain,disclosure,disclosure_hash,terms,created_at,expires_at,can_text,can_voice:false}`. Public summary omits replica_id and all source IDs/hashes, receipt metadata, source material and teaching projection. Owner unknown-publish recovery uses same-ID status, never new ID automatically.

Visitor GET `op=open&public_id=...` returns `{publication}` safe landing. POST `op=join` sends `{public_id,expected_disclosure_hash,is_adult:true,accept_ai_disclosure:true,accept_retention:true}` and returns `{publication,session_token,expires_at,remaining_questions}`. Authenticated adult self-attestation is explicitly not verified age. Session expires after at most12 hours and is bound to visitor/publication/version/disclosure/current admission epoch. No relationship memory.

Visitor POST `op=ask` sends `{public_id,session_token,request_id:<client UUID>,question}`. GET `op=result&public_id=...&request_id=...&session_token=...` replays, never invokes a model. Both return `{request}`: `{public_id,request_id,state:'pending'|'complete'|'blocked'|'uncertain'|'withdrawn',billing_state,failure_code?,answer?,can_voice:false,created_at}`. Question1..2000 UTF16 units, malformed Unicode/control text rejected. Same UUID+same payload reads existing result; changed payload409. Every admitted request consumes one lifetime publication/visitor question allowance even if blocked or uncertain. No automatic retry of a pending/uncertain request. Results belong only to the authenticated visitor.

Visitor POST `op=forget` sends `{public_id}` and returns `{forgotten:true,private_payload_erased:true}`. It erases that visitor's request payloads, revokes sessions and leaves content-free request tombstones/counters to prevent replay/quota reset. Visitor can explicitly join again for remaining quota. Publication revocation, source withdrawal or replica erasure blocks old results and dispatch.

Store exports all accept `(db, actorUserId, input, options={env})`: `readTextPublicationReadiness`, `publishTextPublication`, `readOwnedTextPublication`, `unpublishTextPublication`, `openTextPublication` (actor null permitted), `joinTextPublication`, `forgetTextPublicationVisitor`, `readTextPublicationRequest`, `admitTextPublicationRequest`, `claimTextPublicationRequest`, `completeTextPublicationRequest`, `failTextPublicationRequest`. Admission returns `{created,request,compilerInput}`; claim receives base public_id/request_id/session_token plus `{reservation,provider:{family,name,version,model,prompt_hash}}` and returns `{dispatch_token,request}`; complete receives base plus `{dispatch_token,answer,raw_output,gate:{gated:true,finding_count},billing_state}`; fail receives base plus `{dispatch_token?,failure_code,billing_state}`. Only `created:true` admission may reserve/claim. Provider request namespace `text-publication:<request_id>`; existing Azure structured adapter and provider ledger only. Compile `engine.compilePublishedMaterialAssistant(admitted.compilerInput)`, then shared output/never/honesty gates. For never rules admission also supplies `{owner_user_id,replica_id}` internally; never return these to the visitor.

`compilerInput={authority:{scope:'account_material_publication',basis:'account_material_publication/v1',ownerId,replicaId,publicationId,requestId,visitorId,projectionHash,receiptHash,sourceHash},projection,contexts:[{itemId,sourceId,hash,body}],question}`. Authority is persisted and revalidated by store, not established by compiler. Empty private memory; no first-person verified identity claims.

Configuration: existing private-text KEK is used through a distinct publication encryption/AAD and session domain; no private ciphertext compatibility. `TEXT_PUBLICATION_BUDGET_USD` is a required positive bounded per-publication lifetime cap (maximum10USD), in addition to existing global Azure budget. Fixed v1 reviewed terms: signed-in self-attested adults,30days publication,30days request retention bounded by publication expiry,20 questions per visitor,200 total; conservative token reservation amounts permanently consume publication cap (no refund estimate). Missing encryption/budget is waiting on platform. No environment setting is written by this work.

All errors `{error:<code>,request_id?}`;400 malformed request/attestation,401 auth,404 unknown/foreign IDs,409 stale review/session/revoked authority/conflict,429 quota,503 platform/budget/encryption/uncertain DB. Exact codes use `text_publication_` prefix. Public unavailable states must not expose private rejection detail.

Contract correction: result reads use authenticated **POST `op=result`**, with `{public_id,request_id,session_token}` JSON body. No session token in any URL. This remains read-only and never dispatches.

Terminal pre-publication cancellation has a distinct persisted summary: `{public_id,replica_id?:string,state:'revoked',version:1,publication_never_created:true,can_text:false,can_voice:false,created_at,expires_at}`. It has no title, terms or disclosure receipt because it never published. Owner status/unpublish, late publish replay and public open may return this alternative. Treat it as confirmed private/closed. Normal previously published revocation retains real terms/disclosure but erases projection/title to the generic label `AI text`. No revoked ID can activate again.

Lifecycle implementation uses a fourth **content-free** `vy_text_publication_id_ledger` containing only UUID, kind (`publication` or `request`) and claimed timestamp. A unique insert claims each ID in the same creation statement, so IDs cannot be deliberately reused after erasure or a conflicting row deletion during an INSERT wait. This prevents old public-link and spend-reservation reuse. This is not another agent registry. `CRON_SECRET` at least24characters is an additional platform prerequisite; expiration cleanup has an authenticated scheduled caller. Source/consent withdrawal, unpublish, visitor forget and expiry use fresh cleanup statements after terminal state commits, covering rows the first statement snapshot could not see during lock waits. Readiness history excludes never-created tombstones; direct status keeps their explicit terminal union.

Exact UI types: drafts `{sheet_id:string,name:string,updated_at:string,status:string}[]`; context_items `{item_id:string,source_name:string,status:string,format:string,authorship:string,source_id:string|null,source_ready:boolean,eligible:boolean,reason:string|null}[]`; statements `{id:string,text:string}[]`; terms `{audience:'signed_in_adult_attestation',publication_days:30,retention_days:30,visitor_question_limit:20,total_question_limit:200,budget_microusd:number,quota_policy:'admission_counts',memory:false,voice:false}`. Blocker state one of `ready|needs_input|unavailable|stopped`. Selected projection is `{name:string,subjectDomain:'physics'|'chemistry'|'maths',syllabusScope?:string,languageTextRule?:string,technicalTermRule?:string,explanationOrder?:string,workedExamplePattern?:string,firstMoveOnDoubt?:string,notationConventions?:string,subjectStrands?:string[],examTrack?:string[],doubtEscalationLadder?:string[],rigorFloor?:string[],warmth?:number,strictness?:number,pacePreference?:'push'|'balanced'|'drill'}`. Identity biography and credentials are excluded from the public projection. UI can present each projection key/value as reviewed teaching choices; do not infer verified identity from the name.
