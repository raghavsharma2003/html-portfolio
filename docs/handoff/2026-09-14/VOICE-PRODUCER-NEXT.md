## Five measurable acceptance tests

1. **Ancestry/coverage:** actual native recordings and deliberate PTS gaps, offsets, splices and tail injections. Every admitted audio/video interval maps to original bytes; zero silent truncations or unobserved intervals labeled verified. Malformed/unsupported inputs must reject or remain unavailable. Assert actual decoder/model receipts, not fake embeddings.
2. **Visible/audible association:** participant-disjoint annotated heldout captures. Report frame/interval precision, recall, missed speech and track switches per locale/device, plus end-to-end wrong-person acceptance. All deterministic audio/face substitution controls must fail final acceptance. Raw ASD benchmark mAP does not count as ownership accuracy.
3. **Single-speaker and temporal attacks:** short inserted speakers, overlap and offscreen speech at all clip positions. Report minimum detectable insertion duration and per-attack false accepts/false rejects with counts; no whole-clip average may hide missing intervals. Any confidently accepted known mismatch blocks promotion.
4. **Synthetic/replay decision:** hold out generator and replay-device families; include synchronized fakes that can pass ASD. Report per-attack/locale error rates, reliability/CLLR or Brier diagnostics for any proposed probabilistic score, and participant-clustered uncertainty. Freeze score semantics, fusion and calibration before holdout; evaluate the unchanged0.85/0.02 cutoffs only after that mapping is defensible. A small zero-error pilot is not evidence of2% per-clip risk; risk posterior also needs a stated population/prior. Missing acceptable error/uncertainty targets are an explicit acceptance decision, not values for the engineer to invent.
5. **Real authority and resource path:** exact Azure image/model receipts; recorded input binds Face/reference/attempt; expired/swapped/erased/revoked authority prevents dispatch and settlement; unknown model/coverage/risk refuses. Measure actual real-media latency, peak resource usage and cleanup under the existing bounded executor. Success must reach the real registry/settlement caller under synthetic test authority before any consenting user's grant; mocks alone establish only control flow.
