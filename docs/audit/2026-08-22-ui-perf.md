# UI/perf audit — 2026-08-22 (4th auditor: UI by eye + perf measured)

Method: 101 screenshots across 320/390 widths, both themes, keyboard states;
contrast measured from live computed styles; perf via Event Timing API,
resource timing, A/B stub rebuilds, and the bundled real chess engine in node.
Screenshots were in the session scratchpad (ephemeral); numbers preserved here.

Status legend: FIXED (this session's batch) / TASKED / OPEN.

## CRITICAL

1. **Ttt marks invisible; winning line never renders.** `@keyframes tt-draw`
   has `from { stroke-dashoffset: 1 }` and NO `to` — the implicit `to` reads the
   underlying value, which the same rule sets to 1. Animates 1→1, `forwards`
   freezes it hidden. Every fresh mark invisible until the next re-render;
   the last mark of every game + `.tt-win-stroke` invisible forever.
   `ttt.css:185` / `TicTacToeBoard.tsx:113`. — FIXED

## HIGH

3. **Dark chess: black pieces 1.27:1 on dark squares** (`--cb-black #1b1315`
   on `#33272a`); squares 1.73:1 apart. Light theme fine (4.36/2.75).
   `chess.css:134-156` + byte-identical media block. — FIXED
4. **Chat opens 187px short of newest message** — photo bubbles have no
   intrinsic height (`.msg.photo img` no aspect-ratio), 187px CLS per photo.
   — FIXED (aspect-ratio 340/272 + onLoad re-pin)
5. **985 kB single JS chunk** (326 kB gz). Stub A/B: @anthropic-ai/sdk
